# Student Information Management System

## Overview

The Student Information Management System is a frontend-based web application designed to manage student records efficiently using IndexedDB for local browser storage.

The system allows users to:
- Add student records
- View student information
- Update student details
- Delete student records
- Store data locally without any backend

This project demonstrates client-side database management using IndexedDB.

---

## Features

- Add Student Information
- View Student Records
- Update Student Details
- Delete Student Data
- Search Student Records
- Local Data Storage using IndexedDB
- Responsive User Interface
- No Backend Required
- Offline Data Storage Support
